# RAG-Based-Data-Analyst-System

## Project Description
This project is a Retrieval-Augmented Generation (RAG) based data analyst system that answers questions from a CSV dataset using LangChain, FAISS, Hugging Face embeddings, and Ollama.

## Features
- Load CSV data
- Create vector embeddings
- Retrieve relevant records
- Answer user questions using a local LLM

## Technologies Used
- Python
- LangChain
- FAISS
- Hugging Face Embeddings
- Ollama
- Pandas

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python rag_analyst.py
```
